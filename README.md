# Daily Stock Study

매일 저녁 주식 개념 1강을 그날의 실제 뉴스 사례와 함께 배우고, 용어를 눌러 뜻·공식·영어 표현을 확인하며, 저장한 용어는 간격 반복(FSRS)으로 복습하는 개인용 주식 공부 앱(PWA)입니다.

> **현재 상태: 계획 승인 대기** — 아직 앱 코드는 없습니다.
