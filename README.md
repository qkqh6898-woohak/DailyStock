# Daily Stock Study (주식공부)

매일 저녁 주식 개념 1강을 그날의 실제 뉴스 사례와 함께 배우고, 용어를 눌러 뜻·공식·영어 표현을 확인하며, 저장한 용어는 간격 반복(FSRS)으로 복습하고, 내 투자 판단을 일지로 기록·회고하는 개인용 주식 공부 앱(PWA)입니다.

> **교육용 정보이며 투자 권유가 아닙니다.** 특정 종목의 매수·매도를 권하거나 목표 주가를 제시하지 않습니다.

- 앱 주소(GitHub Pages 설정 후): https://qkqh6898-woohak.github.io/DailyStock/
- 계획 문서: [plan.md](plan.md) · 조사 문서: [research.md](research.md)
- 매일 강의를 만드는 예약 작업 지시문: [prompts/daily-task.md](prompts/daily-task.md)

## 주요 기능

| 탭 | 내용 |
|---|---|
| 📘 오늘 | 커리큘럼 순서대로 하루 1강(약 5분) · 3줄 요약 · 본문 듣기 · 공식 · 오늘 뉴스로 보기 · 영어 표현 · 퀴즈 3문제 · 연속 학습일 |
| 🔁 복습 | ⭐ 저장한 용어를 FSRS 일정대로 복습(다시·어려움·알맞음·쉬움 + 다음 간격 표시), 용어→뜻 / 뜻→용어 / 영어→한국어 |
| 📒 일지 | 매수·매도·관심 기록(이유 20자 이상, 확인할 지표, 예상 위험), "다시 볼 날"이 되면 오늘 화면에 회고 알림 |
| 🧮 계산기 | 복리·적립식(연도별 그래프), PER·PBR·ROE(둘을 알면 하나 역산), 배당수익률(세전·세후), 평단가 |
| ⚙️ 설정 | 음성·속도, 글자 크기, 다크 모드, 하루 새 용어 수, 목표 기억률, 배당 세율, 백업·복원·전체 삭제 |

그 밖에: 용어장(검색·트랙·정렬·상태 필터, 뜻 수정, 직접 추가), 진도(8개 트랙 68강), 지난 강의, 토요일 주간 퀴즈(그 주 용어 + 틀린 문제 + 숫자를 바꾼 계산 문제), 오답 노트, 오프라인 동작.

**숫자 안전장치**: 강의 본문의 숫자는 모두 출처·기준일이 있는 `facts` 에서만 나옵니다. 숫자 옆 ⓘ 를 누르면 출처와 기준일이 보입니다.

**개인 정보**: 용어장·복습 기록·투자 일지는 **이 기기의 브라우저 저장소(IndexedDB)에만** 저장되고 서버로 보내지 않습니다. 앱은 강의 파일을 읽어 오는 것 말고는 네트워크를 쓰지 않습니다(보안 정책으로 다른 서버와의 통신을 막아 둠).

## 설치하기

### Android (Chrome)
1. Chrome에서 앱 주소를 엽니다.
2. 오른쪽 위 ⋮ 메뉴 → **앱 설치**(또는 **홈 화면에 추가**). 앱 안의 오늘 화면이나 설정 화면에 **설치** 버튼이 보이면 그걸 눌러도 됩니다.
3. 홈 화면의 **주식공부** 아이콘으로 실행합니다.

### iPhone (Safari)
1. **Safari**에서 앱 주소를 엽니다(다른 브라우저 앱에서는 홈 화면 추가가 안 될 수 있음).
2. 아래쪽 공유 버튼(□↑) → **홈 화면에 추가**.
3. iPhone은 Safari와 홈 화면 앱의 저장 공간이 따로입니다. Safari에서 쓰던 기록은 백업 → 가져오기로 옮기세요.

### 노트북 (Chrome · Edge)
주소창 오른쪽의 설치 아이콘(⊕)을 누르거나, 그냥 브라우저 탭에서 써도 됩니다.

## 사용법

1. **평일 저녁 8시경** 새 강의가 올라옵니다(알림 메일이 옵니다).
2. 오늘 화면에서 강의를 읽고, 파란 점선 용어를 눌러 카드를 확인합니다. 카드의 ⭐ 를 누르면 복습에 추가됩니다.
3. 끝까지 읽고 퀴즈 3문제를 풀면 **강의 완료**로 기록되고 진도·연속 학습일에 반영됩니다.
4. 복습 탭의 숫자 배지는 오늘 복습할 용어 수입니다. 잘 기억나는 정도에 따라 버튼을 누르면 다음 복습 날짜가 정해집니다.
5. 투자 결정을 했다면 일지에 "왜 그렇게 판단했는지"를 적어 두고, 다시 볼 날(기본 3개월 뒤)에 회고합니다.
6. **토요일**에는 그 주 강의로 만든 주간 퀴즈가 열립니다.

## 백업과 다른 기기로 옮기기

기록은 기기마다 따로 저장됩니다. 기기를 바꾸거나 브라우저 데이터를 지우면 사라질 수 있으니 가끔 백업하세요(14일이 지나면 앱이 알려 줍니다).

1. 설정 → 💾 데이터 → **백업 파일 저장** → `DailyStock-backup-YYYY-MM-DD.json` 이 저장됩니다(용어장·복습·퀴즈·진도·**일지**·설정 포함).
2. 다른 기기에서 앱을 열고 설정 → **백업 파일 고르기**.
   - **병합(추천)**: 지금 기록에 합칩니다. 같은 항목은 더 최근에 고친 쪽을 남깁니다.
   - **덮어쓰기**: 지금 기기의 기록을 모두 지우고 백업 내용으로 바꿉니다.
3. 백업 파일에는 개인 투자 기록이 들어 있습니다. 공개된 곳(이 저장소 포함)에 올리지 마세요.

## 문제 해결

| 증상 | 해결 |
|---|---|
| 오늘 강의가 안 보여요 | 강의는 평일 저녁 8시경 올라옵니다. 그 전이나 주말에는 가장 최근 강의가 보입니다. |
| "새 버전이 있어요"가 떠요 | **새로고침**을 누르면 최신 앱으로 바뀝니다. |
| 화면이 이상하거나 옛날 그대로예요 | 앱을 완전히 닫았다 다시 엽니다. 그래도 안 되면 백업 후 브라우저의 사이트 데이터를 지우고 다시 엽니다. |
| 🔊 버튼이 없어요 / 소리가 안 나요 | 브라우저가 음성 읽기를 지원하지 않거나 기기에 음성이 없습니다. 설정 → 발음에서 음성을 고르거나 기기 설정에서 음성(TTS)을 설치하세요. |
| 비행기 모드에서 강의가 안 열려요 | 한 번 이상 열어 본 강의만 오프라인에서 열립니다(지난 강의 목록의 💾 표시). |
| 기록이 사라졌어요 | 사생활 보호(시크릿) 창이었거나 브라우저 데이터가 지워진 경우입니다. 백업 파일이 있으면 가져오기로 되살릴 수 있습니다. |
| 일지가 다른 기기에 없어요 | 일지는 기기 안에만 저장됩니다. 백업 → 가져오기로 옮기세요. |

## 개발

빌드 도구 없이 순수 HTML/CSS/JS(ES Modules)로 만들었습니다. Node.js 20 이상이면 도구와 테스트를 돌릴 수 있고, 설치할 패키지는 없습니다.

```bash
node tools/serve.mjs            # http://localhost:8080 에서 앱 실행
```

### 명령어

| 명령 | 하는 일 |
|---|---|
| `node tools/validate.mjs <강의.json>` | 강의 파일 하나 검증 |
| `node tools/validate.mjs --all` | 전체 강의 + 커리큘럼 + 용어 사전 + 목록 일관성 검증 |
| `node tools/calc-check.mjs <강의.json>` | 계산 문제·계산값만 검산 |
| `node tools/merge-terms.mjs <강의.json>` | 강의의 새 용어를 `glossary/terms.json` 에 추가 |
| `node tools/build-index.mjs` | `lessons/index.json` 다시 만들기 |
| `node tools/next-lesson.mjs [--date YYYY-MM-DD]` | 오늘 만들 강의 번호·제목·핵심 용어(예약 작업용) |
| `node tools/sw-version.mjs` | 앱 파일을 고친 뒤 서비스 워커 버전 갱신(`--check` 는 점검만) |
| `node --test tests/*.test.mjs` | 단위 테스트 |
| `node tests/smoke.spec.mjs` | 실제 브라우저로 사용 흐름 확인(Playwright 필요) |

> 앱 파일(`js/`, `css/`, `index.html` 등)을 고쳤다면 `node tools/sw-version.mjs` 를 실행해야 사용자 기기에 새 버전이 전달됩니다. 빠뜨리면 테스트가 실패해서 알려 줍니다.

### 폴더 구조

```
index.html, manifest.webmanifest, sw.js   앱 진입점·설치 정보·오프라인
css/app.css                               스타일(라이트·다크)
js/                                       화면과 로직(main 라우터, lesson, review, quiz, journal, calc, settings …)
vendor/ts-fsrs.umd.js                     간격 반복 라이브러리(MIT)
icons/                                    앱 아이콘
curriculum/curriculum.json                8개 트랙 68강
glossary/terms.json                       누적 용어 사전(예약 작업이 갱신)
lessons/index.json, lessons/YYYY/MM/*.json 날짜별 강의
tools/                                    검증·목록·사전·서버 도구
tests/                                    단위 테스트 + 스모크 테스트
prompts/daily-task.md                     예약 작업 지시문
```

### 강의 파일 규칙(요약)

자세한 형식은 [plan.md](plan.md) 3장과 [prompts/daily-task.md](prompts/daily-task.md) 를 보세요.

- 본문 숫자는 직접 쓰지 않고 `facts` 에 넣은 뒤 `{{f:번호}}` 로 참조합니다. `facts` 항목에는 값·단위·기준일·https 출처가 필수입니다.
- 용어는 `[[id]]` 또는 `[[id|표시]]`. id 는 이 강의 `terms` 또는 `glossary/terms.json` 에 있어야 합니다.
- 퀴즈는 concept·calc·case 각 1문제. 계산 문제는 `calc.vars`/`calc.expr` 로 검증기가 직접 계산해 정답을 확인합니다(`eval` 을 쓰지 않는 자체 계산기).
- "매수 추천", "목표가", "지금 사야" 같은 표현은 검증에서 실패합니다.
- `"sample": true` 인 강의는 맛보기로, 진도와 강의 번호 계산에서 빠집니다(현재 샘플 3개: 1강·9강·21강).

## 운영 메모

- **배포**: GitHub 저장소 Settings → Pages → Branch `main` / `(root)` → Save. 1~2분 뒤 앱 주소가 열립니다.
- **예약 작업**: [prompts/daily-task.md](prompts/daily-task.md) 내용을 Claude 예약 작업(평일 19:43 KST)에 넣고, `{{받는 사람}}` 자리에 본인 메일 주소를 적습니다. 메일 주소는 저장소에 커밋하지 않습니다.
  - 예약 작업 설정에 **저장소 `qkqh6898-woohak/DailyStock`** 과 **Gmail 연결**을 꼭 붙입니다. 예약 작업 세션에서는 저장소를 스스로 붙일 수 없어서, 빠지면 강의를 main 에 올리지 못합니다.
  - 2026-11-30 전에는 실행돼도 건너뜁니다. 설정을 바꾼 뒤에는 "테스트 실행"이라는 안내를 붙여 한 번 돌려 확인합니다.
- **GitHub Actions**: 강의·앱 코드가 바뀌면 `validate`(검증 + 단위 테스트)가, 앱 화면 코드가 바뀌면 `smoke`(브라우저 테스트)가 자동으로 돕니다.
